Product Label Creator

Barcode

The barcode value is the record key, so it is needed even when the barcode is not printed. Keep space for price and barcode leaves a blank strip at the bottom of the label (on by default) so a price or barcode can be added later; turn it off to use that room for the content. Auto picks EAN-13 for 13 digits, UPC-A for 12 digits and Code 128 for anything else. EAN-13 and UPC-A check the check digit, or add it if you leave it out. Print the PNG at 100% (actual size) on a laser printer, then test-scan it.

Records

Records are saved in this browser and keyed by the barcode value. Tap a saved record (or type its barcode in the field above) and press Load. Add, Change and Delete are at the bottom of the form. Export a backup now and then — clearing the browser's site data removes saved records. Importing merges with existing records; the same barcode is overwritten by the file.

Basics

The product category decides which icons are suggested first, how Auto picks an icon from the words you type (the same word can mean different things per product), and which quick-add features you see. Changing it never edits features you already typed; Auto icons are re-picked, icons you chose by hand stay. General lists every icon.

Size

The preview is drawn to scale. The PNG is exported at 300 DPI and carries its real size, so print it at 100%. Sizes marked compact are too small for the slogan band and the strip kept for price and barcode, so choosing one switches both off (you can switch them back on).

Features

Type a feature and an icon is matched automatically; pick another icon from the dropdown. If nothing matches you get a search link, or choose Custom image URL to paste your own icon. The quick-add chips add a feature in one tap. If a feature has no icon, press Request an icon on its row: it is kept in the Icon requests list under the feature list (saved in this browser); press Copy list and send it along so the icons can be added.
